# Molecules

Feature-agnostic compositions. If it mentions a specific route or domain entity, it probably belongs in `pages/`.

| File | Role |
|------|------|
| `FormField.tsx` | Label + control + hint/error wrapper |
| `FormActions.tsx` | Cancel + submit row for standard forms |
| `ListPage.tsx` | List/admin page shell (width, header, intro) |
| `SearchField.tsx` | Labelled admin search input |
| `TableActions.tsx` | Horizontal group of table row buttons/links |
| `ModalShell.tsx` | Portal overlay, scroll lock, panel chrome |
| `ModalActions.tsx` | Cancel + confirm row for modals |
| `PageHeader.tsx` | Title row with optional primary action |
| `HintBanner.tsx` | Left-bordered hint / status line |
| `EmptyState.tsx` | Centered empty card with optional CTA |
| `SignInPrompt.tsx` | `HintBanner` + login link (used on gated pages) |
