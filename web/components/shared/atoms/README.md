# Atoms

One job each; no feature imports. Styling tokens for buttons live in `lib/styles/button.ts`; atoms apply them.

| File | Role |
|------|------|
| `Button.tsx` | All button/link CTAs (`variant`, `size`, optional `href`) |
| `IconButton.tsx` | Icon-only controls (studied, play, dismiss ×) |
| `FieldError.tsx` | Inline or block validation/server error text |
| `InlineCode.tsx` | Monospace chip for slugs and technical values |
| `Input.tsx` | Text fields (`default`, `auth`, `modal`, `table`) |
| `Textarea.tsx` | Multi-line input |
| `Select.tsx` | Native `<select>` |
| `Label.tsx` | Form label + optional hint/error slot |
| `Badge.tsx` | Small status chips (e.g. `system`) |
| `TextLink.tsx` | Styled Next.js `Link` |
