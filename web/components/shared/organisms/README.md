# Organisms

Reusable UI blocks that may orchestrate molecules/atoms and client behavior, but stay **domain-neutral**.

| File / folder | Role |
|---------------|------|
| `ConfirmModal.tsx` | Delete/confirm dialog (alertdialog) |
| `DataTable.tsx` | TanStack Table wrapper for admin/list pages |
| `media/ImageLightbox.tsx` | Full-screen image viewer context + provider |
| `media/ZoomableImage.tsx` | Click-to-zoom thumbnail (lessons, vocab images) |
